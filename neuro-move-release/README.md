# NeuroMove Release

A premium web release for the NeuroDecoder MI-BCI system.

Structure:
  backend/   - Python FastAPI service wrapping the existing BCI engines
  frontend/  - React + Vite premium UI with 3D visualization

The backend uses the existing project virtual environment:
  D:\eeg-minirocket-project\.venv

This repo is intended to be a clean release artifact separate from the
exploratory work in the parent project tree.
